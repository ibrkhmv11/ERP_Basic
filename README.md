# Educational ERP & LMS Platform 🏢🌐

A full-stack collaborative Educational ERP (Enterprise Resource Planning) and LMS web application built with **Django**, designed to streamline academic operations, student administration, course tracking, and role-based management.

---

## 🚀 Key Features & Team Contributions

* **Profile Management & UI Templates (CRUD Operations):** Complete profile lifecycle management across Admin, Mentor, and Student roles, custom avatar handling, and unified, cleaned UI template architecture (*Developed by Ilhom Ahmadjonov*).
* **Core ERP Architecture & Database Design:** System scaffolding, data modeling for academic modules, courses, groups, and base business logic (*Developed by Norbek Ibragimov*).
* **Role-Based Access Control (RBAC):** Dynamic role-dependent dashboard rendering, custom decorators, and view-level permissions (*Collaborative implementation*).
* **Course & Student Administration:** Group assignments, student enrollment flows, and attendance tracking workflows.

---

## 🛠 Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap, Django Templates
* **Database:** SQLite / PostgreSQL
* **Version Control:** Git, GitHub (Collaborative Feature-Branch Workflow)
